# Week 6 Final Data Analytics Project

## Project Overview

This repository contains the end-to-end Final Data Analytics Project developed as part of the Week 6 Data Analytics Internship Assignment.

## Objective

The objective of this project is to apply data analytics concepts including data preparation, exploratory data analysis, data visualization, business intelligence, and business insight generation.

## Analysis Workflow

1. Dataset selection and inspection
2. Data cleaning and preparation
3. Exploratory Data Analysis (EDA)
4. Statistical analysis and correlation analysis
5. Data visualization
6. Power BI dashboard development
7. Business insights and recommendations

## Project Status

Project setup completed. Data analysis and dashboard development are in progress.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Power BI
- Git
- GitHub

- data/ – Dataset files

- src/ – Python source code

- report/ – Final project report
